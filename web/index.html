Ranges on top of the settings above. A blank axis keeps the single value already in the panel, so only what you fill in varies.

?Put {name} placeholders in the prompt above, then give each one its values here, one variable per line:
{size} dog sitting on {ground}
size = big | small
ground = grass | dirt — four prompts, and they cross with the ranges below.
Values split on |, not on commas: a comma belongs to the prompt.
none is a value too — the word and its space come out altogether, so size = big | none compares saying it against not saying it.
Blank runs the prompt exactly as written — and is refused if the prompt still has {placeholders} in it, rather than rendering the braces.
?One value, a list or a range:

?Same syntax:
