# Review - 2026-10-24: gaps against other local UIs and reported use

A read of what the app lacks that other local Stable Diffusion UIs carry,
what Matt's own ratings in `docs/design/preferences.md` imply, and the
development tooling. It left out what the docs already decided or
deferred: own photos as references (`GEN#8`), the masked area only
(`INP#9`), VLM scoring (`PA#9`), klein and Qwen inpaint, and a sampler
control (declined in `docs/design-notes.md`, since it would widen `CellKey`,
the PNG and the database).

The review's list was triaged the same day against the ratings, and Matt
took the triage ("go", 2026-10-24). Each entry below says what was taken,
where its detail lives, and its `TODO.md` row. Two claims in the review were
wrong when checked against the code and are corrected where they apply: a
size axis does not find size already in `CellKey`, and the queue is not a
list.

## Built the same day

### G1. Smoke runner

Each smoke needed a fake server started by hand from `AGENTS.md`'s port
table. `tools/run_smoke.py` reads that table (port, `--model` through the
line under it, `--step`, and the smokes a row runs on one fake, in order),
starts each fake on a gallery of its own in a new temporary directory, runs
the smokes with `browser.mjs`, stops the fake and keeps its log on a
failure. `--offset` moves every port; `--jobs N` runs rows in parallel, each
worker 100 ports further on. `tests/test_run_smoke.py` holds every smoke to
one parsed row with a full checkpoint id. Rules: `docs/rules.md` under Tests.

### G2. Lint and CI

`pyproject.toml` gains a `[tool.ruff]` block limited to correctness
(`E4`, `E7`, `E9`, `F`, `B`, with FastAPI's `Body()` defaults and the
fixtures imported from helper modules allowed) and `ruff` in the dev group.
Its first run found one real defect: `tests/fakes.py` raised `Cancelled`
in `expand_prompt` and `translate` without importing it, so a stopped fake
expansion would have raised `NameError`. `.github/workflows/ci.yml` runs
ruff and the CPU suite on Ubuntu on every push, pull request and by hand;
Linux, since a runner minute there costs half a Windows one on a private
repository and the suite already runs under WSL.

### G7. Queue: move to front, and skip one cell

Queueing, cancelling running and cancelling queued work are all Often (D4,
D7, D8). Corrected: the queue is not a list. A queued job waits on the
generation gate, an `asyncio.Lock` (`backend/jobs.py:348`), and is admitted
in the order the lock wakes its waiters, so move to front needs an
admission order of the manager's own, kept with `setQueue`'s rows. Skipping
the running cell is the cooperative cancel for one cell: `Cancelled` from
the callback, recorded as a skipped cell so Resume and Finish can make it
later. M each. `GEN#18`.

### G8. Size as a grid axis, and a crop anchor for Refine

Resolution tiers and Re-render at another size are Often (A4, G7).
Corrected: `CellKey` does not carry size (`backend/grid.py:100-108`);
`run_id` hashes it once per run and `gallery_reports.runs` reads one size
off a run's oldest image (`backend/gallery_reports.py:255-266`), and the
resume lookup reads keys at one size (`backend/submission.py:303`). A size
axis widens the key and gives a run more than one size, so it is L, not M.
`refine.fitted` scales to cover and centre-crops (`backend/refine.py:479`),
so a Refine to another shape loses a portrait's head; an anchor is a
reproduction field too. Both widen the key: plan them together and widen it
once. `GEN#19`.

### G9. Keyboard shortcut overlay

## Matt's call

### G10. A1111-style weighting and long prompts on SDXL

`(word:1.2)` is literal today and every overflow past 77 tokens is cut
(`docs/usage.md`; `docs/design-notes.md`). Weighting and chunking are
standard in anime workflows, but they change what an existing prompt with
parentheses renders, so they could only be opt-in, recorded in the chunk
and in the key. Worth a plan only if Matt writes weighted prompts. L plus
card. `GEN#20`.

## Not taken

Recorded so the next review does not raise them again without a reason:

- **Tags from an image (an interrogator).** Matt's own renders carry their
  prompts; tagging outside images implies importing them, which is
  `GEN#8`, deferred; references are rated Never (I3).
- **ControlNet, visual similarity search, variation seeds.** XL or L each,
  and nothing in the ratings asks for them; references and LoRAs are Never
  (I1-I4). Variation seeds would be per-pipeline work, since the backend
  hands pipelines generators, never latents.
- **A denoise-free GAN upscale.** Enlarging through Refine covers it (H2),
  and opening original PNGs is Never (J3).
- **Prefetching the next checkpoint and a byte-progress load.** Switching is
  Sometimes (K1) and loading by hand Never (K7). A small "free this
  checkpoint's cache" control (`huggingface_hub.scan_cache_dir`) would be
  reasonable on its own if disk becomes a problem.
- **A face and hand detailer (auto-mask).** Inpaint is Sometimes (H7);
  revisit after G4, since a batch form would build on the same in-job
  second pass.
