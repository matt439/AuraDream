## Design implications to evaluate

| Task | Placement derived from the answers |
|---|---|
| Compose and generate | Prompt/negative, separate Aspect/Resolution, readable fixed Seed, Batch/Repeat and undoable Reset direct; Steps/CFG/Mu one disclosure away with current values visible |
| Prompt assistance | Examples, guide/help, Tags/autocomplete/chips and Check beside authoring; token detail, corrections/Undo, critic/rewrite, prompt comparisons and ERNIE Expand contextual secondary; PNG settings secondary |
| Prompt variables and grids | Direct access to prompt-variable authoring; Steps/CFG, seed count, preview and Resume readily available within the occasional grid workflow; Mu/LoRA sweeps, explicit seed list and time budget secondary |
| Queue and return | Active progress, elapsed/estimate, job switching, queued work, cancellation, retry and reconnect prominent; preview optional; Pause secondary but any actual paused state explicit |
| Browse and judge | Starred, All models, prompt search, recent runs, settings-to-search and cross-filter selection direct; card density/Fit-Crop, large-image inspection and contact sheet/Fill width important |
| Visual workspace | Dedicated Gallery/sheet view instead of the existing Gallery-beside-newest arrangement; do not interpret this as rejecting a persistent composer beside Gallery |
| Continue and rerun | Direct Reuse, Use seed, batch/picked-filter/run More seeds, Re-render, Swap tags, mass star and Mass refine; scope and count remain explicit |
| Edit keepers | Refine and enlarge, strength/version comparison and Mass refine prominent; revised prompts and Inpaint/Outpaint occasional; cross-checkpoint/already-refined mass inclusion secondary |
| Archive at session end | Whole-gallery backup, password protection, Bundle and clear, saved downloads/import visible at the curation endpoint; selected/starred bundles secondary |
| Model choice | Favourites, sourced guidance/examples/timing and remembered auto-load prominent; switching and WSL occasional; quantization/offload/save-without-load/manual weight controls secondary |
| Supporting interactions | Keyboard, right-click and Ctrl/Shift selection remain direct alternatives; terminal workflows need no primary browser UI space |

### Interpret the distinctions accurately

- Main-panel random generation is Never; More seeds of a batch, selected set
  and whole run are Often. Keep all those continuation routes.
- Choosing/reordering references and LoRAs is Never, but reusing an image's
  recorded references is Sometimes. Preserve contextual reference reuse,
  active-input visibility and reproduction metadata.
- Adjusting Mu is Sometimes; sweeping Mu is Never. These are different actions.
- Browsing All models is Often; including other models/existing passes in
  Mass refine is Never. Keep those inclusion choices independent.
- Picks are frequent; picked/starred bundles are Never. Keep whole-gallery
  archive as the primary archive route without changing bundle scope rules.
- Contact sheets and Fill width are frequent; sheet export is Never.
- B is now explicitly answered: the frequent authoring tools stay adjacent
  to Prompt, while the occasional critic/rewrite/comparison/Expand tools
  remain available in context. PNG settings is Never. Do not infer these
  ratings from unrelated prompt-variable or tag-swap answers.
- Resolution-tier selection is frequent. No particular aspect, tier, numeric
  seed, Batch, Repeat or sampling value has been chosen by these answers.
